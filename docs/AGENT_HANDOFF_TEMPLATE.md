# Agent Handoff Template

Copy this template into every implementation draft PR.

```text
Phase: P<n>
Role:
Base branch:
Commit SHA:
Draft PR:

Changed paths:
-

Decision IDs implemented:
- D__

Contract or migration IDs:
-

Tests and commands:
- command:
  result:

Compatibility impact:

Known limitations or blockers:

```

Do not include secrets, production identifiers, raw audio, access tokens, or
full sensitive transcripts in the handoff.
